# P3 实机验收指引（ChKSz 在线接入与歌词）

> 配套 PLAN.md 第 10 节 P3 验收标准。先确认 `data/config.json` 里已有有效 Key（设置页 → 在线 可查看/测试），再按顺序走。全程不需要 ASIO 设备，普通输出即可。

## 一、设置页在线组

1. 打开 设置 → 在线 组，确认显示已配置的 Key（脱敏展示），或先粘贴 Key 点「保存」。
2. 点「测试连接」：状态行应出现"连接正常（剩余额度 N）"。**这一步消耗 1 次额度**，是 Key 校验的唯一真凭据。
3. 播放条右侧出现额度指示（如"API 剩 358"）；未填 Key 时显示"在线未启用"。

## 二、歌词自动匹配（核心体验）

1. 播放一首**中文流行歌**（标题+歌手在网易云常见的），打开歌词覆盖层（点击播放条左下角封面）。
2. 预期 3~5 秒内出现滚动歌词：当前行高亮并居中，随播放推进自动滚动；顶部显示来源（"在线 · 已匹配网易云 {id}" 或 "缓存"）。
3. 验证四件事：
   - **点击某行** → 播放进度跳到该行时间点，高亮同步。
   - **模式切换**（底部"双语"按钮）：原文 → 双语（原文+翻译）→ 罗马音 循环，翻译行跟随。
   - **偏移 ±0.1s**：点"偏移 +0.1s"数次，高亮行相对歌声位置整体后移；**切歌再切回来偏移仍保留**（持久化）。
   - **关闭/重开覆盖层**（Esc 或右上角关闭）：再次打开时歌词仍在。
4. 播放一首**无人声/纯音乐**或很冷门的歌：歌词页显示"未找到"类提示（安静降级，**不弹窗、不影响播放**），右上角「重新匹配」可手动搜索候选。

## 三、手动重新匹配

1. 歌词页点「重新匹配」：弹出候选列表（标题-歌手·时长，按相似度排序）。
2. 选一个候选点「应用」（或双击）：歌词立即刷新为该曲目；「清除匹配」则以后不再用在线歌词。
3. 重新匹配的选择要**持久化**：切歌再切回，歌词仍用你选的那首（不重新自动匹配）。

## 四、本地 .lrc 优先级

1. 找一首歌，在它同目录放同名 .lrc（例如 a.flac → a.lrc），内容随意几行带时间标签。
2. 播放它并打开歌词页：显示"本地 .lrc"，且**不会**发在线请求（额度指示数字不动）。
3. 无时间轴 .lrc（纯文本）：整篇静态显示，无滚动高亮，但可点偏移。

## 五、降级与健壮性

1. **断网**：拔网线（或关代理）后播放一首未匹配过的歌 → 歌词页安静显示未找到，本地播放不受任何影响，额度指示保持原值。
2. **无 Key**：清空 Key 保存 → 播放任何歌都无在线行为，播放条显示"在线未启用"；重填 Key 后恢复。
3. **连续操作不触发 429**：连续快速切 20+ 首歌（每首触发自动匹配）→ 不应出现"请求过于频繁"错误；日志里令牌桶正常工作。

## 六、回归（P0–P2 不应被破坏）

1. 本地播放/暂停/seek/音量/上下曲/播放模式照常。
2. ASIO/WASAPI 输出指示与位完美灯照常（歌词功能不碰输出链路）。
3. 退出无残留进程。

## 预期行为速查

| 场景 | 预期 |
| --- | --- |
| 填 Key + 中文歌 | ≤5s 出滚动歌词，当前行高亮居中 |
| 匹配错歌（同名翻唱） | 「重新匹配」手动改选，选择持久化 |
| 无 .lrc 且匹配失败 | 安静"未找到"，不弹窗 |
| 断网 / 402 | 歌词功能降级，本地播放不受影响 |
| 同目录 .lrc | 永远优先，不发请求 |
| 歌词偏移 | ±0.1s 步进，按曲目持久化 |
