## 主要改动

### 音频与生命周期

- END 回调只写入 FIFO mailbox，由单一 worker 顺序消费；曲目身份代际与 Pause/Seek 等控制意图代际分离，无缝交接事实不会被迟到控制误丢，旧的自然 END 仍不会误续播。退出时先停止回调、排空预载和待释放句柄，再释放 BASS。
- 后端恢复通知合并为单飞工作项，以 backend identity + generation 丢弃迟到的旧设备事件；ASIO 驱动通知使用无分配 mailbox，回调线程不读 BASS 属性、不写日志、不派发 UI 事件。
- 预载采用 generation 校验和任务跟踪；取消或切歌后，作废任务只能释放资源，不能把旧曲重新挂回播放链。
- 频谱红线保持不变：`mixer DSP tap → 预分配 SPSC ring → 后台 FFT`。频谱路径不对解码流或混音流调用 `ChannelGetData`；项目中唯一真实调用仍属于 WASAPI 输出拉流。

### 媒体库、歌词与在线能力

- 媒体库扫描完成后一次性发布不可变快照，索引、专辑/艺术家/文件夹聚合与曲目序列来自同一批对象；watcher 补扫使用单 worker 原子 pending 协议，扫描收尾边界不再丢最后一次目录变化。
- 在线搜索和歌词请求采用取消透传与 latest-wins；旧封面、旧歌词不会在新曲目上短暂复用。下载进度按整数百分比节流，终态只通知一次。
- 定位当前曲目时清除过期过滤并展开目标分组；响应式列宽每次尺寸变化只计算一次，主列表和窄窗布局减少重复测量。
- SMTC 在无曲目/停止态清理旧元数据，避免系统媒体控件继续显示已结束曲目。

### UI 与迷你窗

- 主列表三栏边界收敛，侧栏、列表和右信息栏不再出现可见缝隙；`1400×900` 与窄窗截图表头/行保持对齐。
- 迷你窗默认歌词，悬停后显示上一首/播放暂停/下一首/歌词⇄频谱；歌词长行按实际测量缩小字号，不使用省略号。
- 迷你窗固定浅/深表面色，不再参与封面染色；模式切换才申请/释放频谱租约。
- 移动改为设备像素 `SetWindowPos` 的轻量原生循环，不依赖系统是否显示拖动中的窗口内容；拖动期间暂停跑马灯、频谱计时器和歌词动画，松手后合并保存位置。
- 四边四角保持 `0.8×–2.0×` 整体等比缩放；双击非交互区域恢复 `340×104`，双击封面返回主窗，Esc/托盘/主窗退出仍由统一协调器处理。
