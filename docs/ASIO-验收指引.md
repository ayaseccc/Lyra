# ASIO 实机验收指引

> 验收设备：**TOPPING E1x2 OTG**（2 进 2 出 USB 声卡，专用 ASIO 驱动 + TOPPING Professional Control Center v1.13）
> 对应阶段：P2（ASIO / WASAPI 独占 / 无缝播放）
> 沙盒只能验到编译与决策逻辑，**出声效果必须在这台设备上实听**。

---

## 0. 开始之前

1. 关掉其它可能占用声卡的程序。ASIO 驱动通常**只允许一个客户端**，foobar2000、Reaper、OBS、其它 ASIO 播放器同时开着，Lyra 就打不开设备（面板本身不算客户端，可以开着）。
2. 打开 TOPPING Professional Control Center，摆在旁边——右上角会实时显示**当前采样率**与**缓冲区大小**，「采样率跟随源文件」这条验收就靠它。
3. 面板里确认 **Playback 1/2 的混音路由是通的**（Mix A–D 那块）。听不到声先查这里，不要先怀疑播放器。
4. 准备至少三个不同采样率的音频文件，例如 44.1 kHz 的 CD 抓轨、48 kHz 的曲子、96 kHz 或更高的 Hi-Res。同一采样率的连续两首也要有（验无缝用）。

---

## 1. 选设备与通道

1. 解压根目录的 `Lyra-v1.0.3-win-x64.zip`，启动解压目录中的 `Lyra.exe`；左下角齿轮进设置页，最上面就是**输出**组。源码调试也可直接运行 Release 构建。
2. 「后端」选 **ASIO**。设备下拉里应出现 TOPPING 的 ASIO 设备；没有的话点右边「刷新」，还没有就是驱动没装或被别的程序占着。
3. 「ASIO」那一行右边的下拉是**输出声道对**，默认 **Playback 1/2**。E1x2 有 1/2 ~ 7/8 多路回放，播放器只输出一对；耳机/线路输出接的是哪一对，就选哪一对（一般是 1/2）。
4. 设置改动**即时生效**，不需要重启程序。改完看输出组底部那行状态，应显示形如：
   `ASIO · TOPPING E1x2 OTG · 44100 Hz · 缓冲 256 samples`
5. 左侧栏底部也有一行常驻的输出指示，**前面有个蓝点就表示当前是位完美输出**（音量 100% 且没有重采样）。鼠标悬停能看到具体原因。

> 提示：程序**空闲时不占设备**——输出设置只是记下来，真正打开 ASIO 是在第一次播放时。所以设完之后要放一首歌才能在面板上看到变化。

---

## 2. 采样率跟随（本阶段最核心的一条）

「采样率」保持默认的 **跟随源文件（位完美）**。

1. 播放一首 **44.1 kHz** 的曲子 → 看 Control Center 面板：采样率应显示 **44100**。
2. 直接切到一首 **48 kHz** → 面板应跳到 **48000**，切换瞬间允许有极短的静默（重建链路，属正常）。
3. 再切到 **96 kHz**（或 192 kHz）→ 面板应跳到对应数字。
4. 播放器左下角的输出指示与面板数字应该始终一致。

**若某个采样率设备不支持**：播放器会明确提示"设备不支持 xxx Hz（它支持 …），可在设置里改用固定采样率"，并回退到系统输出而不是崩掉。这时把「采样率」改成 **固定采样率 + 重采样**，选一个设备支持的值（E1x2 一般 44100/48000/96000 都支持）。

**位完美确认**：音量拉到 100%，采样率跟随模式下播放，左下角蓝点亮起 = 播放器这一侧没有做任何音量衰减或重采样。再往上就是驱动和硬件的事了，可用面板确认没有额外的采样率转换。

---

## 3. 无缝播放

1. 找**同一采样率**的连续两首（最好是现场专辑或 DJ mix 这种本来就该连着的）。
2. 建一个歌单或直接在文件夹虚拟歌单里连着放，让它自然放完第一首。
3. 曲目切换时应该**听不到任何停顿或咔哒声**；播放器状态栏会显示"无缝衔接：<下一首标题>"。
4. 对照实验：把两首**不同采样率**的排在一起，切换时会有一个极短的静默（面板采样率同时跳变），这是设计如此，不是 bug。

原理：同采样率时下一曲会提前 5 秒预解码，交接发生在混音线程的样本边界上（`MixerChanNoRampin`，无淡入淡出）。

---

## 4. WASAPI 独占（次选路径，也要验一次）

1. 后端切到 **WASAPI**，设备选 TOPPING（或你的默认声卡），「独占模式」打开。
2. 播放 → 应正常出声；此时**其它程序的声音会被切断**，这是独占的正常表现。
3. 独占失败的典型提示：「设备已被别的程序以独占方式占用」或「设备在独占模式下不支持 xxx Hz / 2 声道」。前者关掉占用的程序，后者改用共享模式或固定采样率。
4. 关掉独占开关 → 变共享模式，应能与其它程序同时出声。

> 已知限制：程序为了兜底会一直保持 BASS 的默认输出设备处于初始化状态，个别系统上这可能让 WASAPI 独占打不开同一个端点。真遇到就用 ASIO（本机首选路径）或换共享模式。

---

## 5. 爆音 / 断续怎么办（先调缓冲，再看日志）

**你当前面板里的缓冲区是 32 samples**，这对录音监听是好事，对纯播放偏激进，容易在系统忙时爆音。

排查顺序：

1. **先调缓冲区**：设置页「ASIO」那行左边的下拉，从「驱动首选」依次试 **128 → 256 → 512**。播放器请求的缓冲区会被自动夹到驱动允许的范围内。多数情况到 256 就干净了。
2. 面板里的缓冲区也可以同步调大（面板设置优先级更高）。
3. 还不行再看日志：`<Lyra.exe 所在目录>\data\logs\lyra-YYYYMMDD.log`。搜 `ASIO` 能看到设备名、实际采样率、缓冲区、延迟；搜 `Error` / `Warning` 看有没有 BASS 错误码。
4. 日志里若出现 `ASIO 设备复位通知` 或 `ASIO 已停止`，说明是驱动侧掉了，不是缓冲区问题。

---

## 6. 破坏性测试（必做，验的是"不崩 + 能回退"）

> 这几项会打断播放，放在最后做。

**A. 播放中拔 USB**
1. ASIO 后端正常播放中，直接拔掉 E1x2 的 USB 线。
2. 期望：程序**不崩溃**；状态栏出现「ASIO 设备已复位或断开，已自动切回系统输出」；播放从原位置继续（走系统输出，可能从笔记本喇叭出声）。
3. 插回 USB → 到设置页把后端重新选回 ASIO（不会自动切回去，这是有意的：避免和驱动重连打架）。

**B. 设备被别的程序抢走**
1. Lyra 正在用 ASIO 播放时，打开另一个 ASIO 程序去占用同一台设备。
2. 期望：Lyra 检测到设备停止后回退系统输出并提示，不崩。
3. 反过来：先让别的程序占着，再让 Lyra 切 ASIO → 应提示「ASIO 驱动打不开：多数是被别的程序占用了」并留在系统输出。

**C. 播放中禁用系统默认声卡**（可选）
1. 用系统输出后端播放时，在 Windows 声音设置里禁用当前默认设备。
2. 期望：程序不崩，日志里出现「系统输出通道已停止」。

**D. 切换轰炸**
1. 播放中连续快速切换：ASIO → WASAPI 独占 → WASAPI 共享 → 系统输出 → ASIO。
2. 期望：每次都能出声，播放位置保持，不崩，不需要重启程序。

## 7. 验收对照表

| # | 验收项（PLAN P2） | 怎么判定 |
|---|---|---|
| 1 | ASIO 设备正常出声 | 选 ASIO 后能听到声音，面板显示对应采样率 |
| 2 | 采样率跟随源文件 | 44.1k / 48k / 96k 三首切换，面板数字跟着变 |
| 3 | WASAPI 独占出声 | 切 WASAPI + 独占能出声，其它程序被静音 |
| 4 | 同采样率连续曲目无缝 | 切歌听不到停顿，状态栏显示"无缝衔接" |
| 5 | 播放中拔设备不崩并回退 | 拔 USB 后程序继续跑，提示已切回系统输出 |
| 6 | 切后端不需要重启 | 第 6 节 D 项切换轰炸全程不重启 |
| 7 | 位完美提示准确 | 音量 100% + 跟随采样率 → 蓝点亮；音量调低或改固定采样率 → 蓝点灭 |

有任何一条不过，把 `data\logs` 下当天的日志一起发回来，日志里 BASS/BASSASIO 的错误码是定位的关键。
