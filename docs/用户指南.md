# Player — 本地音乐播放器

轻量、本地优先的 Windows 音乐播放器。支持 FLAC / MP3 / M4A / APE / WV / OGG / OPUS / WAV / AIFF。

## 快速上手

1. 解压 zip，双击 Player.exe。
2. 首次运行会弹出引导：**选曲库目录 → 选输出设备 → API Key（可跳过）**。
3. 曲库目录会自动扫描入库；侧边栏浏览「全部歌曲 / 专辑 / 艺术家 / 文件夹」，双击播放。
4. 双击资源管理器中的音频文件（或拖到 Player.exe 图标上）会用 Player 打开并播放——
   程序是单实例：重复打开只会把文件转交给已在运行的实例。

## 常用操作

- **播放控制**：播放/暂停、上一曲/下一曲、停止、进度拖拽；右键列表可「播放 / 下一首播放（插队不打断）/ 打开所在文件夹 / 复制 / 移动 / 重命名 / 删除 / 属性 / 添加到歌单 / 移出歌单 / 歌词来源」
- **列表**：平铺/专辑分组切换（工具栏）、分组标题点击折叠、列头排序；设置里可调行高、列显隐/顺序/宽度、字号缩放、菜单风格（复古/现代）
- **歌词**：桌面歌词（右下角小柄解锁后可拖动调宽、锁定穿透）、大歌词页（双击/按钮打开）；歌词来源（本地 .lrc / 内嵌 / 在线）可在右键或设置里指定
- **迷你悬浮窗**：播放条画中画按钮打开；四边四角可整体缩放（80%–200%），双击非按钮区域恢复默认；位置与大小自动记忆
- **在线**：在线搜索（试听/下载）、歌词在线获取；API Key 在设置 → 在线页填写

## ASIO 说明

- 需要声卡厂商的 ASIO 驱动（板载声卡可用 ASIO4ALL）。
- 设置 → 播放 → 后端选 ASIO；采样率默认跟随源文件；缓冲建议 256 samples。
- ASIO 为独占设备，启用期间其它程序将无声；无 ASIO 需求用 DirectSound 即可。

## 数据与配置

- 配置、日志、媒体库数据库都在程序目录 data\ 下（便携，整个目录拷走即迁移）。
- 配置文件损坏时自动备份（config.json.corrupt-时间戳）并重建，不会崩溃。
- 关闭窗口 = 最小化到托盘（设置可改）；退出请用托盘菜单「退出」。
