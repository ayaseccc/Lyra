## 新增功能

### 最常听 / 最近播放

- 播放统计（`play_count` / `last_played`）自 v1.0 起每次播放自动落库，本次补上呈现层：侧边栏「媒体库」组新增两个入口，各 Top 50（量级适配小曲库）。
- 最常听：零播放不入榜，按次数降序、同次数按最近播放排前（榜单不僵死）。最近播放：按时间降序，未播放不入榜。
- 复用现有曲目列表页：右键菜单、双击播放、添加到歌单、过滤全部可用。进页现查，正在听的歌下次进页自然上榜。
- 空态与曲库空态区分：显示「多听几首，这里就会出现你的最常听和最近播放」。
- harness 新增 `stats` 模式 9 项（排序 / 过滤 / 同次数平局 / limit / 空库），进入常规回归基线。

### 侧边栏显示项自定义

- 实机反馈：媒体库选项太多。设置 → 媒体库新增「侧边栏显示项」六个开关：专辑 / 艺术家 / 最常听 / 最近播放 / 在线搜索 / 下载管理。
- 黑名单式配置（`Ui.SidebarHiddenItems`，默认全显，老配置自然兼容）；开关即时生效并持久化。
- 「全部歌曲」不可隐藏：空曲库引导与扫描刷新依赖它存在。

## 修复

### 播放器界面（v1.0.3 实机反馈）

1. **右栏（歌词栏）拖拽弹回**：列宽改单向数据流（VM 通知 → 窗口显式写列宽，拖完 `DragCompleted` 读 `ActualWidth` 回写），根除 TwoWay 绑定与 GridSplitter 增量计算失同步的回路。
2. **拖窄自动收起**：低于 200 DIP 松手自动收起并禁用 splitter（0 宽时往左拖不再误抓窗口边框）；折叠前宽度持久化，展开恢复用户习惯宽度。
3. **窗口几何记忆**：还原尺寸与最大化状态分开持久化；几何变化即防抖落盘（崩溃 / 强杀不丢）；贴边（Win11 Snap）用 `GetWindowPlacement` 与 `GetWindowRect` 矩形差识别，贴边期间不把半屏尺寸写进还原尺寸；弃用 `RestoreBounds`（贴边 / 最大化后返回陈旧矩形，「重启回预设尺寸」的根因）。
4. **恢复默认尺寸**：「恢复默认外观」新增窗口几何重置（解除最大化并回 1400×900，此前无恢复入口）。
5. **长歌词拖栏卡顿**：拖动期间 LyricCanvas 沿用旧排版，停手 150ms 后整表重排一次；不再逐帧重建上百个 FormattedText。
6. **列头换页瞬态溢出**：换页时优先用 `MainContentHost.ActualWidth` 现算视口宽；列头 Border 加 `ClipToBounds`——结构上不可能再画进右栏。

### 稳定性（v1.0.4 实测反馈）

7. **侧边栏快速切换卡死**：根因是每次导航在 UI 线程同步做整套重建（查库 → ObservableCollection → CollectionView → 分组 → 整页视觉树），连续点击叠加引爆。修复：120ms 导航节流 + 同项重复点击直接跳过（顺带保留滚动位置 / 多选 / 列排序）。实测真实库 80 轮 × 40ms 极限轰炸，停止后 1 秒内完全恢复。
8. **切页导航栏跳动**：侧栏搜索框在非列表页整体隐藏导致占位塌缩。改为常驻 + 页面感知禁用（占位符「仅在曲目列表页可用」），导航栏像素级零位移。

## 评估与决策记录

- **Embeat 推荐系统**：读源码评估后放弃——需自部署 Qdrant（数十 GB 向量库 + 常驻服务）与便携定位冲突；推荐对象是 Spotify 在线曲库而非本地文件；Track2Vec 权重未发布（五路召回缺主力一路）。结论已回写 `docs/v1.0-终审报告.md` Backlog 备忘。
