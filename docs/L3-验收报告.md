## 四、音频技术红线（频谱）

- 样本只由 **mixer 上的 BASS DSP 回调**复制到预分配 **SPSC 环形缓冲**（262144 float）
- DSP 回调：**不分配、不加锁、不执行 FFT、不写日志、不修改 PCM**（仅 Interlocked 计数 + 复制）
- 后台分析线程：Hann 窗 + 48/96/192 kHz → 2048/4096/8192 点 FFT（≈42.7ms 分析窗）+ 对数 16 柱（50Hz-20kHz）+ 平滑/衰减/180ms 宽限期
- 租约引用计数管理 DSP 生命周期；mixer 重建只恢复当前注册；epoch+generation 防旧回调 ABA
- DirectSound UpdatePeriod=20ms（默认输出供样稳定）
- **ChannelGetData 全项目仅 WASAPI sink 一处，频谱路径零调用**
