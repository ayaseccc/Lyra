## 最终功能

- 迷你窗内容为 `Lyrics / Spectrum` 二选一，切换按钮位于迷你窗悬停控制区，替换旧返回按钮。
- 未配置或空配置统一默认歌词，不再由旧 `MiniSpectrum=true` 改写默认模式。
- 模式切换立即保存 `miniContentMode`，并同步维护旧 `miniSpectrum` 字段用于配置兼容。
- 歌词模式释放频谱 DSP 租约并停止 33 ms UI 计时器；频谱模式才申请 mixer DSP tap。
- 第一行显示当前歌词原文，第二行优先显示翻译/罗马音；没有副文本时显示下一句。
- 切歌加载期间显示“加载歌词…”，不会短暂残留上一首歌词。
- 歌词不使用省略号；通过 `FormattedText` 测量实际宽度并分别缩小两行字号，保证单行完整显示。
- 双击封面返回主窗且不退出进程；双击其他非交互区域恢复默认 `340 x 104`。
- 捕获鼠标后使用 `SetWindowPos` 实时移动。拖动期间冻结跑马灯、频谱、歌词刷新和动画，释放后异步保存位置。
- 保留四边四角等比例缩放，范围为默认大小的 80% 至 200%。
- 迷你窗不参与封面染色，仅使用固定深浅调色板；主窗口封面主题不受影响。

## 音频技术红线

- 迷你窗不持有音频 handle，不调用 BASS 读取接口。
- 频谱样本只由 mixer 上的 DSP 回调只读复制到预分配 SPSC 环形缓冲。
- DSP 回调不分配、不加锁、不执行 FFT、不写日志、不修改 PCM。
- Hann 窗、双声道功率合并、FFT、平滑和暂停衰减均在后台分析线程执行。
- 48/96/192 kHz 分别使用 2048/4096/8192 点 FFT，约保持 42.7 ms 分析窗。
- 频谱租约以引用计数管理；最后一个消费者释放后卸载 HDSP，mixer 重建只恢复当前注册。
- 全部 C# 源码中唯一真实 `ChannelGetData(...)` 调用仍位于：
  `Player.Core\Audio\WasapiBackend.cs:139`
