## 实装范围

- 新增统一的 `AppSurfaceCoordinator`，集中管理主窗、迷你窗、托盘和桌面歌词的显隐、恢复与退出语义。
- 新增完整迷你悬浮窗：默认 340 x 104 DIP，整体等比缩放范围 80% 至 200%，四边和四角均可调整；双击非交互区域恢复默认尺寸。
- 迷你窗可在非按钮、非进度条区域自由拖动，位置、显示器和比例尺寸会持久化；失效显示器坐标会被纠正到可见工作区。
- 拖动和缩放使用 Windows 原生移动循环；移动期间冻结频谱、标题跑马灯和悬停布局，并缓存 DPI/显示器命中数据，降低窗口拖动卡顿。
- 迷你窗保留 64 x 64 封面、标题、歌手/专辑、上一首、播放/暂停、下一首、返回主窗、频谱和可拖动进度条；悬停控制不会再挤掉歌曲信息。
- 迷你窗染色功能已完整删除：没有设置项、配置字段、封面取色、覆盖层或主题服务注入；仅使用固定深色/浅色调色板。主窗口原有封面主题染色不受影响。
- 主界面左右侧栏与中间列表之间的可见缝隙收敛为 1 px 分隔线，同时保留透明拖拽命中区；列表根部横向空隙已移除。
- 关闭到托盘、托盘恢复、迷你窗恢复、桌面歌词和真正退出由同一协调器管理；退出路径幂等，托盘建立失败时不会把主窗隐藏成残留后台进程。

## 音频技术红线

- 频谱样本只由 mixer 上的 BASS DSP 回调复制到预分配的 SPSC 环形缓冲。
- DSP 回调不分配、不加锁、不执行 FFT、不写日志、不修改 PCM。
- Hann 窗、双声道功率合并、FFT、平滑和暂停衰减均在后台分析线程执行。
- 48/96/192 kHz 分别使用 2048/4096/8192 点 FFT，约保持 42.7 ms 分析窗。
- 频谱租约以引用计数管理 DSP；最后一个消费者释放后卸载 HDSP，mixer 重建时只恢复当前注册。
- DirectSound 的 `Bass.UpdatePeriod` 调整为 20 ms；无 PCM 时保留 180 ms 宽限期，避免默认输出分批供样造成频谱反复衰减和起峰。
- 源码静态检查确认：频谱、ViewModel 和迷你窗路径均没有 `ChannelGetData` 调用。唯一实际调用位于 `Player.Core\Audio\WasapiBackend.cs`，用于 WASAPI 输出 sink。
- `MiniSpectrum` 默认值仍为 `false`，不会在真实 ASIO 硬件验收前自动开启。
